⚔️ Attack — Chrome DevTools Frontend Manipulation

VERY IMPORTANT
What attacker tries
1. Open Chrome DevTools → Elements tab
2. Find entitlement cell in the DOM
3. Double-click, change 1.0000 → 9999
4. Or in Console: ledgerEntries[0].entitled = 9999
5. Try to trigger a payment for the inflated amount
Why it completely fails
• Frontend is display-only — renders blockchain state
• Smart contract reads its own EVM storage, not the browser DOM
• Contract: entitled[wallet] lives on Polygon, cannot be edited from a browser
• Page refresh calls syncBlockchainData() — overwrites all DOM edits instantly
