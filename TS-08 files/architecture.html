📊 VanAdhikar Frontend

  • 9 pages: Dashboard, Ledger, Payments, Alerts, Family, Dispute, DTDO, Immutability, Cooperative
  • Bilingual: English + Gujarati (Tiro Devanagari)
  • Sidebar layout with page-routing SPA pattern
  • Demo mode + Live MetaMask mode
Stack: ethers@5.7.2 + qrcodejs + vanilla CSS

🖥️ SecureTx/Kilo Console

  • 4 views: Overview, Tokens, Multisig, Activity
  • Dark theme with light/dark toggle
  • Multisig transaction builder (5 tx types)
  • Gasless proposals via EIP-712 signatures
Stack: ethers@6.11.1 + dark CSS

📜 Smart Contract

  • SecureTransactionSystem — production-grade multi-feature contract
  • ERC-20 mDAI with EIP-2612 permit (gasless approvals)
  • Multisig: M-of-N signatures, configurable 1h–30d timelock
  • RBAC: 4 roles, emergency pause, reentrancy guard
  • EIP-712 typed data for off-chain signature collection
Deployed: 0x5a82…A47Ce on Polygon Amoy

🌐 Blockchain Layer

  • Polygon Amoy Testnet (Chain ID 80002)
  • ~2 second block time, low gas fees
  • On-chain immutability proven by absence of DELETE/EDIT
  • All transactions verifiable on PolygonScan
Public explorer: amoy.polygonscan.com

🔒 Security Properties

  • Reentrancy protection via OpenZeppelin guard
  • Role-gated admin functions (no single point of failure)
  • Timelock delay before multisig execution
  • Immutable on-chain records (no edit/delete)
  • Cryptographic proof via EIP-712 signatures
Audit-ready: security.html demonstrates attack scenarios

  • No build step — open HTML directly in browser
  • All deps via CDN (no npm install needed)
